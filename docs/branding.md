# Ratatoskr

Ratatoskr is the squirrel that runs along Yggdrasil carrying messages between the eagle above and Níðhöggr below in Norse mythology. The project's name fits a messenger carrying skills between agent environments.

The original app artwork is a copper-red squirrel with a curled tail, tufted ears, cream details, and an acorn. Sage accents match the desktop UI. It was generated with OpenAI's built-in image generator in generation mode, with a transparent background, then converted into desktop icon sizes by the Tauri icon command.

Master artwork: `desktop/public/ratatoskr.png`. Desktop bundle assets: `desktop/src-tauri/icons/`.

Prompt: original desktop app icon for Ratatoskr Skill Sync, the Norse messenger squirrel; compact side-profile squirrel with a large curled tail, tufted ears and an acorn; clean recognizable silhouette, warm copper-red and cream with a sage accent, polished modern app illustration, transparent background, no lettering, square composition. No competitor assets or logos were used.
